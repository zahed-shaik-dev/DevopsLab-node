# Node Docker App

A beginner-friendly DevOps project demonstrating how to containerize a Node.js application using Docker.

## Project Overview

This project is created to practice the basic Docker workflow:

Node.js Application
        ↓
    Dockerfile
        ↓
   Docker Image
        ↓
  Docker Container
        ↓
   localhost:3000
